# Что менялось

Коротко и по-человечески: что появилось в каждой версии. Полная история — в `git log`.

Запускалка показывает три последние строки отсюда после обновления, поэтому формат простой: строка начинается с версии, дальше через тире — суть.

## 1.5 — 10.09.2026

- `codium --txt` снимает рамки вокруг русских слов — это Unicode-подсветка, а не тема
- в Restricted Mode эта проверка включена принудительно, поэтому гасится ключами
- кириллица объявляется своим алфавитом, защита от подделок в коде остаётся

## 1.4 — 10.09.2026

- `codium` — редактор настраивается командой: .txt как простой текст, без подсветки
- VSCodium становится приложением по умолчанию для .txt
- настройки редактора правятся своим блоком, чужие ключи не трогаются

## 1.3 — 09.09.2026

- прозрачность окна теперь держится сама: сторож стартует сразу, а не со следующего входа
- `app ИМЯ --opacity N` больше не требует `--keep` — разовая установка ушла под `--once`
- `app --windows` показывает, что настроено, даже когда приложение закрыто

## 1.2 — 09.09.2026

- `app --windows` — список окон с их именами и текущей прозрачностью
- прозрачность окна теперь проверяет результат, а не только рапортует об успехе
- если окно не нашлось — показывает список открытых окон с их именами для команды

## 1.1 — 09.09.2026

- `tabby` — стеклянный терминал одной командой, правит Custom CSS самого Tabby
- `app ИМЯ --opacity N` — прозрачность окна любого приложения, включая Electron
- `look` — весь вид одной командой: work, night, paper
- `profile save/load` — снимок оформления целиком и возврат к нему
- банк тем вырос до 21, банк значков — до 20
- VSCodium в раскатке, `bootstrap.sh` больше не дублирует инструмент
- проект переименован в `kubeelinux`

## 1.0 — 27.08.2026

- первый единый `desktop-kit.sh` вместо россыпи модулей
- кнопки заголовка, углы, темы, значки, шрифты, обои, виджет, клавиши
- откат по подсистемам и `selftest` с архивом логов
